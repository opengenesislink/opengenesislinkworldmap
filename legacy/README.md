# Historische Projektbasis

Die ursprüngliche ZIP-Datei `openSIMULATOR-Map-Karte-master.zip` enthält die PHP-Karte,
Installationsroutine, alte Kartenbilder und die Variante `MaximumMap`.

**Nicht direkt auf einem öffentlichen Produktions-Webserver ausführen.**
Insbesondere der öffentliche Installer und die SQL-Implementierung sind veraltet.
Der neue WorldMap-Code implementiert die benötigten Funktionen unabhängig davon.

Das vollständige Original ist Teil des separat erzeugten Migrationspakets.
