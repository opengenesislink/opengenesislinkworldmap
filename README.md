# OpenGenesisLINK WorldMap

Eigenständige interaktive Regionskarte für **OpenGenesisLINK** und **OpenSimulator**.

Die Projektentwicklung baut auf den Funktionen der älteren **openSIMULATOR-Map-Karte** auf. Die neue Generation setzt auf PHP 8.2+, eine eigene JSON-API und eine moderne, responsive Kartenoberfläche.

## Entwicklungsstand

Der Projektimport wird über den Branch `feature/worldmap-generation-1` vorbereitet. Die erste Umsetzung unterstützt Regionsdaten, Standard- und VarRegions, Koordinatennavigation, Suche und eine read-only PDO-Datenbankanbindung.

**GitHub:** https://github.com/opengenesislink/opengenesislinkworldmap

Neue Codebestandteile stehen unter MPL-2.0. Der ursprüngliche ZIP-Quellcode wird als historisches Referenzmaterial separat erhalten.
